# FRAME

**FRAME** is a personal, non-commercial Windows desktop application for organizing, browsing, and watching video content.

The application is built with C#/.NET and Avalonia UI.

## Features

- **Local Video Library** — Add, organize, search, and play videos stored on your computer.
- **Telegram Integration** — Browse video catalogs from Telegram groups and channels using your own Telegram account.
- **Video Player** — Watch supported videos with playback progress tracking.
- **Online Cinema** — Browse online video websites using an integrated browser.
- **Movie & TV Catalog (In Development)** — Discover movies and TV shows with posters, descriptions, ratings, and search powered by TMDB.

## Technology

- C# / .NET 10
- Avalonia UI
- SQLite
- TDLib
- libmpv
- WebView2

## Project Status

FRAME is currently under active development and is intended primarily for personal use.

The source code and application binaries are not publicly distributed at this time.

## TMDB Integration

FRAME plans to use the TMDB API to retrieve movie and TV show metadata, including titles, descriptions, posters, genres, ratings, and release dates.

TMDB is used exclusively as a metadata provider. FRAME does not host or distribute movies or TV shows.

This product uses the TMDB API but is not endorsed or certified by TMDB.
